【CPU 重建】L2/B0一次[调用](APPENDIX_beginner_glossary.md#g080)：当前颜色、有效[历史](APPENDIX_beginner_glossary.md#g024)/[MV](APPENDIX_beginner_glossary.md#g023)、[params](APPENDIX_beginner_glossary.md#g083)→16[通道](APPENDIX_beginner_glossary.md#g007)[F16](APPENDIX_beginner_glossary.md#g054)条件→32通道[窗口](APPENDIX_beginner_glossary.md#g015)块→[full](APPENDIX_beginner_glossary.md#g018) X₀(32)与pool X₁(32) [E4](APPENDIX_beginner_glossary.md#g055)。五步是核内步骤，不重复计launch覆盖。
共享合同：F16适配用[K16](APPENDIX_beginner_glossary.md#g065)；主干E4[矩阵](APPENDIX_beginner_glossary.md#g051)逐K32[发布](APPENDIX_beginner_glossary.md#g091)half；转换、[残差](APPENDIX_beginner_glossary.md#g017)与half池化各保留舍入点。缺[资源](APPENDIX_beginner_glossary.md#g079)和原语域外仍拒绝；[p5](APPENDIX_beginner_glossary.md#g032)选择按下钻的条件通道合同执行。

| 核内步骤 | 本步特定作用与交接 | 下钻 |
|---|---|---|
| <a id="noise"></a>噪声 | 未[镜像](APPENDIX_beginner_glossary.md#g030)(x,y,f)散列→三路half噪声，无递推[RNG](APPENDIX_beginner_glossary.md#g075)[状态](APPENDIX_beginner_glossary.md#g002) | [噪声](L3_b0_input.md#noise) |
| <a id="temporal"></a>历史[重投影](APPENDIX_beginner_glossary.md#g025) | 有效时以MV作[五tap](APPENDIX_beginner_glossary.md#g029)；否则重复当前RGB | [坐标/五tap](L3_b0_input.md#coordinates) |
| <a id="channels"></a>16通道 | p5=false照原控制；reset / 时域分支在p5真时令[structure](APPENDIX_beginner_glossary.md#g005)=1、[mask](APPENDIX_beginner_glossary.md#g006)取CB+0xb8 ([f32](APPENDIX_beginner_glossary.md#g057))/CB+0xbc (f32)，15为[+0](APPENDIX_beginner_glossary.md#g070) | [通道与子候选](L3_b0_input.md#p5-candidates) |
| <a id="adapter"></a>适配与窗口块 | 16→32 F16适配→[FFN](APPENDIX_beginner_glossary.md#g037)→Q/K[归一化](APPENDIX_beginner_glossary.md#g043)→[attention](APPENDIX_beginner_glossary.md#g039)→[投影](APPENDIX_beginner_glossary.md#g038) | [完整块](L3_b0_input.md#adapter) |
| <a id="publish"></a>full/pool | 未[量化](APPENDIX_beginner_glossary.md#g061)结果分流；full量化，pool先固定half 2×2平均再量化 | [布局与算术](L3_b0_input.md#publish) |

p5真时固定structure并从控制缓冲取两个mask，有历史则使用自身历史重投影；[参数分支证据](APPENDIX_evidence_history.md#param-change)（measured on child candidate）。

~~~mermaid
flowchart LR
    N["坐标/帧字→噪声"] --> C["16通道F16"]
    T["当前色/有效MV历史→重投影"] --> C
    C --> A["F16适配16→32"]
    A --> W["FFN→Q/K归一化→attention→投影"]
    W --> F["Q8→full"]
    W --> P["half 2×2平均→Q8→pool"]
~~~
