# 入门词表：遇到才查，不用先背

[入口故事](INDEX.md) · [一块](L1_00_one_block_primer.md) · [历史](L1_00_history_primer.md) · [数点与小篮](L1_00_numbers_primer.md)

111组按新手评审的顺序对应。一个词可能用于图像、算术、执行或检查；尤其构建代号、存储格式和检查状态，都不是新增网络层。这里给基础含义，精确合同仍看原正文。

## 图像、输入与结构

| 词或写法 | 第一次遇见时这样理解 |
|---|---|
| <a id="g001"></a>原生行为、目标二进制 | 原生行为是那份被观察程序实际表现出来的计算；目标二进制是锁定版本与内容身份的程序文件。CPU读源说明不能自动称为观察到了它。 |
| <a id="g002"></a>状态、处理后状态、时域状态 | 为后面步骤或下一帧保存的数。本路线的颜色状态id9/id6、内部特征和整片工作区是不同对象，不能只用“状态”二字合并。 |
| <a id="g003"></a>颜色基底、显示基底 | 本帧原颜色的一份备份，供末端显示混合使用；不是另一个隐藏特征。 |
| <a id="g004"></a>intensity | 显示阶段把处理后颜色与本帧备份混合的强度；它不是B70历史混合份额。 |
| <a id="g005"></a>style、tone、structure | 三个具名控制量，送入条件通道后影响数值；它们各自造成的完整可见效果未定，不能按英文名补一个训练目标。 |
| <a id="g006"></a>automask、skin、mask、skin-mask | 本项目控制/捕获标签中的遮罩或皮肤相关名称；已解释的p5两个mask是标量条件，不是这里另读的逐像素遮罩图。名称不能证明对哪些画面区域起何种作用。 |
| <a id="g007"></a>通道、16→32、512/1024通道 | 通道数是一个位置保存的数字项数；16→32是把16项组合成32项，不是16帧变32帧，也不直接改变图片宽高。 |
| <a id="g008"></a>特征 | 网络内部计算并传递的数。知道它有32项，不等于知道哪项专门表示边缘、皮肤或细节。 |
| <a id="g009"></a>编码、解码 | 此处指前半段逐步降低网格密度、后半段逐步恢复密度的阶段；不是文件编码的正逆运算。数值码的“解码”另见Q8/D8。 |
| <a id="g010"></a>全局瓶颈 | 网络较深、位置较少的一段，位置之间可作全局联系；“瓶颈”在这里不是速度最慢的证明。 |
| <a id="g011"></a>TIN | 本串的一组窗口块与存放布局的家族标签；实际操作由窗口页说明，不从三个字母推架构。 |
| <a id="g012"></a>Swin、Transformer | Transformer通常用注意力交换位置内容、用逐位置计算变换通道；Swin是窗口/移位窗口相关的模型名称。这里的名字用于对照或标识，不证明照搬标准结构。 |
| <a id="g013"></a>split16、16头 | 本串512项窗口块的家族名；比较用数字分16头，每头32项。FFN八组和设备执行分组是另外的轴。 |
| <a id="g014"></a>ViT | 图像位置使用Transformer的常见名字；在本串特指1024项、32头、八个全局块这段，不能按缩写补标准实现。 |
| <a id="g015"></a>窗口、8×8窗、移位窗口 | 只让一组相邻位置在本次注意力中交换内容；8×8是64个位置。下一块换窗口划分起点，可让位置接触另一组邻居，不是把最终图平移。 |
| <a id="g016"></a>skip、旁路 | 较早的数字保存下来，绕过中间一些步骤，再送到后面。保存的是内部数，不必是一张可见图片。 |
| <a id="g017"></a>residual、残差 | 块内绕过子段再接回的数；本串往往先乘尺度、作为矩阵起始小计加入。它与跨阶段skip、显示混合不可混成一个末端加号。 |
| <a id="g018"></a>full、pool、pooled、池化 | full是本档较完整密度的出口，pool/pooled是较稀出口的角色名。池化泛指合并邻域信息；名字本身不决定平均公式，空间对应未定处仍留问号。 |
| <a id="g019"></a>repack、重排、swizzle | 让相同数或位型换存放顺序。例：(a,b,c,d)从两行两格换成一行四格；swizzle在这里指地址位排列，不是额外的内容变换。 |
| <a id="g020"></a>插值、卷积、闭式、归纳 | 插值从已有位置估算其他位置；卷积用一组系数组合邻域。闭式指不靠现成索引表逐项查找的显式规则；归纳是由具名样本总结规律，尚不证明所有输入。 |
| <a id="g021"></a>上采样、下采样、最近邻 | 增加/减少内部网格位置；最近邻把选中的邻近位置数复制过来。本串不同阶段算术不同，不能因此断言最终显示分辨率改变。 |
| <a id="g022"></a>outview、inpview、chained | 输出视图接口、输入视图接口、连续同档块的家族名称；带这些词的调用可能仍做完整数值计算，不是纯换盒子。 |
| <a id="g023"></a>运动矢量、MV | 本路线每位置两个数，参与“去旧图哪里取数”的坐标式。其宿主通用方向/单位未定，必须连同尺度与变换读。 |
| <a id="g024"></a>时域、历史、carry | 时域涉及前后帧；历史是允许读取的旧状态；carry是把自己的状态保存并接续，不是一层新算子。 |
| <a id="g025"></a>重投影、temporal sampling | 用当前位置与移动数求旧图中的取样位置，再过滤取颜色。B0与B70各有自己的变换，不共用一次取样结果。 |
| <a id="g026"></a>alpha、第四通道 | 图像第四个存储分量，图像处理中常用于透明度/覆盖度。本路线不把它当网络颜色输入，结果图固定写1；第四预测量另参与历史份额，不能等同alpha。 |
| <a id="g027"></a>纹理、纹素、TEX | 纹理是可按坐标取样的数字图；纹素是其中一格。TEX在正文表示带指定过滤规则的一次取样，不一定只读一格。 |
| <a id="g028"></a>RGBA16F、RG16F | 每位置分别存R/G/B/第四项，或只存两项；每项用F16。它们是存储表示，不是两种新的网络层。 |
| <a id="g029"></a>tap、五tap、四邻域、双线性、侧瓣 | tap是一处过滤取样点；五tap的每点还可由四邻域过滤。双线性按两轴距离组合四角；侧瓣是中心外的贡献，本串外层可为负，内层另有精度规则。 |
| <a id="g030"></a>镜像、反射、边界取样 | 图像越界时按规定映回边缘内。例如本例1080行外的y=1080映到1078，不是把整张图拉伸。源码副本的“镜像”是另一含义。 |
| <a id="g031"></a>gain、尺度、缩放 | 数字乘一个因子以整体放大/缩小；输入颜色尺度、旁路尺度、查询尺度和显示强度是不同量，不是同一旋钮。 |
| <a id="g032"></a>p5、reset、参数分支 | p5是条件控制分支的标签；reset在已记录合同下不消费旧历史，帧尾用新状态覆盖。分支取决于多个参数/资源条件，不能只改计数。 |
| <a id="g033"></a>HSL、h/s/l、色相、饱和度、亮度式量 | 色相提示红/绿等色类；饱和度提示离灰色多远；亮度式量由颜色极大/极小值构造，非物理照度。本串使用HSL型分解/重组与特定通道次序，精确算式仍是依据。 |
| <a id="g034"></a>Oklab、LMS | 两种颜色坐标相关名称：Oklab以近似感知均匀为目标，LMS与三类视锥响应有关。它们是旧命名对照，不替代这里现行的HSL型算式。 |

## 比较位置与处理通道

| 词或写法 | 第一次遇见时这样理解 |
|---|---|
| <a id="g035"></a>算子 | 一个明确的处理步骤，如求和、改格式、按坐标取数；不是都对应一次设备调用。 |
| <a id="g036"></a>逻辑块、B编号 | 把网络接线按功能分成一块块，B0至B70是这些块的编号；一块可包含多个执行调用。 |
| <a id="g037"></a>FFN、ffwd、ffwd_proj、前馈 | 本块先对各位置的通道串单独处理的子段；ffwd与ffwd_proj是具体家族入口，可能把这段分开执行。此时还不是跨位置内容交换。 |
| <a id="g038"></a>投影、proj、后投影 | 用系数把一串输入数重新组合成另一串；不特指三维画面投影。后投影把注意力内容组合回块通道。 |
| <a id="g039"></a>attention、注意力 | 当前位置给候选位置评分，将正份额用于组合那些位置的内容；读[三个位置的小故事](L1_00_one_block_primer.md#qkv-story)。 |
| <a id="g040"></a>Q/K/V、查询/键/值 | Q用于当前提问，K用于被比较，V用于取回内容；都由内部数算出，分数不是对V本身评分。 |
| <a id="g041"></a>token | 参与处理的一个位置及它的数字串；深层网格的一个位置不必等于原图的一个像素。 |
| <a id="g042"></a>seed | 一次累加开始时带入的小计，可为零、先前小计或旁路数；这里不是生成随机数的种子。 |
| <a id="g043"></a>归一化、norm、norm32、范数 | 调整一组数的整体大小；范数是一种“长度”。本串Q/K每组32项求平方和、取指定倒数平方根再逐项乘，V不走此步，不减平均数。 |
| <a id="g044"></a>LayerNorm、均值、方差 | 均值是平均数，方差是离均值的平方偏差平均量；普通LayerNorm会先居中再按尺度归一。本串的Q/K平方和缩放不是这个入口操作。 |
| <a id="g045"></a>G、门函数、激活 | 每个输入数经一个单输入函数改变，G在这里是裁剪分段多项式再改格式；“门”不表示二选一开关，也不是检查用的验收门。 |
| <a id="g046"></a>GELU、SiLU、SwiGLU | 其他激活/门的名称：GELU按平滑累积分布调输入，SiLU将输入乘平滑S形函数，SwiGLU用两路独立投影逐项相乘。它们是对照对象，不能替换本串G。 |
| <a id="g047"></a>softmax、exp、行最大值 | 普通softmax对一行分数取自然指数exp再除总量；可先减行最大值以控制中间幅值。这里的编码正权重有不同公式，不能因都作份额就认作相同。 |
| <a id="g048"></a>φ、正核、权重w/份额p、Den | φ把分数变正数，w是未除总量的权重，p是除后份额，Den是总量。“正核”的核是函数变换，不是执行的kernel；舍入后p未必正好和为1。 |
| <a id="g049"></a>仿射、clamp/clip、Sat01、夹取 | 仿射在这里是乘常数再加常数；夹取把超范围数拉回最近端点。Sat01夹到0至1，不能与E4有限饱和混同。 |
| <a id="g050"></a>归约、分母树、部分和/Partials | 把多项按指定配对合成较少项；先存的各路小计叫部分和。有限精度下(a+b)+c不一定等于a+(b+c)，树与顺序有意义。 |
| <a id="g051"></a>M×K×N、矩阵、点积、dense、BLAS/GEMM | 矩阵是数表；一行与一列对应相乘再相加是点积。M行各K项乘K行各N项得M×N；dense表示稠密连接/存储语境，BLAS/GEMM是常用线性代数接口/矩阵乘运算，不自带本串舍入合同。 |
| <a id="g052"></a>位置偏置/bias、查询尺度、置信尺度/confidence、sigmoid/logistic | 位置偏置给某对位置的分数加指定项；查询尺度乘Q；置信尺度限制历史混合。sigmoid/logistic是把数变成0至1附近S形份额的函数名，份额不因此成为已校准概率。 |
| <a id="g053"></a>RMS、L2单位向量、ε、β | RMS是平方平均后开根；L2单位向量按平方和开根把长度调为1。ε在本串作平方和下限，不是加上去；β常记附加偏移，本串此缩放后没有β加法。 |

## 有限数与舍入

| 词或写法 | 第一次遇见时这样理解 |
|---|---|
| <a id="g054"></a>F16、half、binary16 | 同一种16位浮点格式，只能保存指定数点，不是16位十进制精度。先读[数轴页](L1_00_numbers_primer.md)。 |
| <a id="g055"></a>E4、E4M3、FP8 | 本串的一字节浮点码，1符号位、4指数位、3尾数位；比F16数点少，不是多一组颜色。E4作为历史捕获代号时另见工作线词义。 |
| <a id="g056"></a>F32、binary32、binary64、双精度、浮点 | 32位/64位浮点数；按二的缩放档位保存有效数，仍有限精度。CPU参考用64位中间数不证明设备内部也用64位。 |
| <a id="g057"></a>f32/u32/u64、U32、raw32、bits16、位型 | f32把32位解作浮点，u32/u64解作无符号整数；raw32/bits16强调原始位串。位串0x3e00按half解作1.5，编码整数与数值不是一回事。 |
| <a id="g058"></a>指数、尾数、字段指数、实际指数、有效数 | 类似6=1.5×2²，1.5是有效数、2是缩放指数。编码存的指数域带偏置/特殊规则，未必等于数值的实际指数；公共格选尺要区分它们。 |
| <a id="g059"></a>RN-even、RN16/RN32/RN64、RNE16、half_round | 找最近的可存数，恰中间才选有效数最低位为0的那个；RN后数字是目标格式位宽，half_round是实现函数名。 |
| <a id="g060"></a>RZ、RZ16、trunc、向零 | 舍掉超出目标精度的部分时朝零靠：正数变小，负数变得不那么负。trunc是截去小数部分的常用名；不能与负数向下取整混同。 |
| <a id="g061"></a>Q8/D8、量化/解码 | Q8把F16送到较粗E4码，可能丢信息；D8把该码精确展开成F16，不能找回先前被丢掉的数。 |
| <a id="g062"></a>satfinite、有限饱和 | 超过目标格式有限端点时取其最大有限幅值；不是夹[0,1]，也不能取消前一步运算的拒绝。 |
| <a id="g063"></a>H+、H×、HF、h_fma、融合乘加/FMA | half加/乘各自保存；融合乘加让乘积在规定的加法之前不单独保存。软件参考保留binary64融合、再到half的边界，不能说成所有硬件通用内部结构。 |
| <a id="g064"></a>累加器、部分和、小计反馈 | 保存当前小计，供下一次累加带入。它已经受先前舍入影响，不是一直保留数学精确总和的袋子。 |
| <a id="g065"></a>K16、K32、Q32、QMMA、HMMA | 本文的16项/32项矩阵累加步骤及硬件原语族简称；数字不是线程数或窗口大小。两族输入格式、截格与证据各自绑定。 |
| <a id="g066"></a>公共格点、对齐指数、格距、field F25 | 同一篮先将乘积和小计放到同一二幂刻度上；对齐指数决定格距。field F25是本目标候选的选尺规则名，实际式见L4，不代表存成一种新F25格式。 |
| <a id="g067"></a>value/renorm候选 | 不同选公共刻度的算术假说：按数值指数或重新归一后的指数处理等；它们是待判别规则，不是两层网络。具体差异以候选表为准。 |
| <a id="g068"></a>正规/次正规、FTZ、tiny、DAZ、渐进下溢 | 次正规是格式靠近零的更小数点；渐进下溢继续用这些点，FTZ把某处微小输入/输出冲成零，DAZ强调输入当零。tiny只是微小量语境，规则须逐操作看。 |
| <a id="g069"></a>Inf、NaN、非有限、NaN载荷/quiet NaN | Inf表示无穷、NaN表示非数，均不属普通有限数；载荷是NaN编码保留的位，quiet是其一类标志。当前接口可能拒绝，不能随意当零。 |
| <a id="g070"></a>+0/−0、有符号零 | 数值比较通常相等的两个零编码；字节比较能区分，某些操作也保留符号。不能用数值相等替代逐位相等。 |
| <a id="g071"></a>上溢/overflow、下溢、相消、动态范围 | 上溢是幅值超格式范围；下溢涉及极小结果；相消是正负项抵消；动态范围描述可同时处理的大与小。实现拒绝是另一个决定。 |
| <a id="g072"></a>RSQ/RCP、EX2/LG2 | 分别提示1/√x、1/x、2的x次方、以2为底对数的用途；本项目要的是指定函数输出位型，不是随便用数学库近似。 |
| <a id="g073"></a>MUFU、SFU、SQRT、SIN/COS、Radius | 前两者是特殊函数相关单元/原语名称；后者是开根、三角函数与组合半径。本串Radius已含多步组合，不是对k直接开根。 |
| <a id="g074"></a>libm、函数包装、认证函数映射/函数表、Domain | libm是普通数学函数库；函数表存指定输入码的指定输出码。包装在外面检查域、改码或舍入；Domain是允许的输入集合。查到表项也不能绕过调用者限制。 |
| <a id="g075"></a>整数散列/Hash32、Box–Muller、RNG、xor、U32回绕 | 散列把位置与计数混成确定整数；xor是按位异或；U32超界按模2³²回绕。RNG泛指随机数发生器，Box–Muller是从均匀数构造集中于零附近扰动的常见方法；本串按固定位置/计数重新算，无逐像素递推状态。 |
| <a id="g076"></a>标量、向量、张量、轴 | 一个数、一串数、多维数表；轴是表的一个维度。逻辑空间/通道轴与设备分配工作的轴不能因长度相同就认作同一个。 |
| <a id="g077"></a>MAC/GMAC、QK、AV、带宽 | MAC计一次标量乘加，GMAC计十亿次；QK是比较得分，AV是按份额组合内容。带宽是单位时间可搬数据量，运算次数表本身不是带宽或速度测量。 |

## 程序执行与存储

| 词或写法 | 第一次遇见时这样理解 |
|---|---|
| <a id="g078"></a>DLL、GPU、SM、sm_120、架构、shader | DLL是程序库文件；GPU执行并行任务，SM是其计算单元组织之一，sm_120锁定目标架构；shader是设备程序的常见名字。它们说明执行对象，不是特征通道。 |
| <a id="g079"></a>权重、WEIGHTS_HT、资源、权重容器 | 权重是计算时乘输入或作尺度/偏置的系数，资源/容器是存放它们的载体；WEIGHTS_HT是本对象的资源名，不代表一种网络操作。 |
| <a id="g080"></a>kernel/核、launch/调用、家族、融合核 | kernel是一段设备计算程序，launch是请求执行一次；家族归并相似入口，融合核把多项计算放一次调用中。算子数、块数、调用数分开数。 |
| <a id="g081"></a>L0/L1阅读层级与launch L0–L157 | 阅读层级指文档深入程度；launch L0–L157指默认执行序号；B编号指逻辑块。标题会同时列三者，不把L2页误作网络第二层。 |
| <a id="g082"></a>工作区、workspace、WS | 存放中间数字、交接区和管理标记的一大片内存；保留它不证明每个旧字节都是跨帧必需记忆。 |
| <a id="g083"></a>params、CB、常量缓冲、字节偏移 | 每次调用收到的一包配置，含尺寸、指针/句柄、控制数等；CB+0x40是包内十六进制字节位置，读出的值和取样算法的1/256网格是不同概念。 |
| <a id="g084"></a>role/角色、pitch/行跨度、Span/基址 | 角色给某时刻一段存储命名；基址是起点，Span是其区间。pitch是相邻行起点相距字节数，可能比有效像素行更长。 |
| <a id="g085"></a>逻辑/物理、T/P、extent、padding/补齐 | 逻辑是位置/通道含义，物理是实际排布；extent是声明尺寸。T为有效位置，P含补齐行。额外格有时真被写/读，不能一律丢掉；最后显示仍裁到输入尺寸。 |
| <a id="g086"></a>batch=1 | 一次处理一份样本；省略的batch轴长度为1，不是把视频的全部帧一起放进去。 |
| <a id="g087"></a>线程、warp、lane、CTA、grid、tile、shared/共享内存 | 线程是执行设备程序的一份工作；本目标将32条线程编为一组warp，lane是组内0..31编号。CTA是含若干warp的协作线程块，grid是一次launch的CTA集合；tile是数据/工作分块，shared是协作块内共用的临时存储。这些工作分组不自动等于图像位置、通道或注意力头。 |
| <a id="g088"></a>描述符、inputlayout/outputlayout、HWC/CHW、分平面 | 描述符记录一份资源的尺寸/格式等；layout指定存放顺序。HWC先位置后通道，CHW先通道后位置；分平面把某些通道组分别存。数字含义可相同，地址可不同。 |
| <a id="g089"></a>mapexec、scalar_map、maps、wiring、DAG、来源图 | maps说“从哪取、往哪写”，wiring/DAG说“哪些结果按什么依赖计算”；DAG是无循环的依赖图。执行器按图求值，不证明图已化成空间闭式。 |
| <a id="g090"></a>sread/xsite/wload/gstore、A_src/B_off、OUTMAP/REDMAP | 具体来源/输出表的名字：共享读取、跨站来源、权重读取、输出写入；A_src/B_off选矩阵输入/权重，OUTMAP/REDMAP选最终输出/规约来源。它们不是新手图中的网络层。 |
| <a id="g091"></a>release/发布、完成标记、wait、同步 | 发布可能指保存数值，也可能写“可读/完成”的管理槽；wait/同步约束任务先后。CPU返回顺序不自动证明设备的全部并发时序。 |
| <a id="g092"></a>别名、生命周期、异步、epoch | 两名字指同一/重叠存储叫别名；生命周期指何时有效；异步允许任务未结束时继续；epoch是执行图的一次阶段/轮次，不自动等于视频帧号。 |
| <a id="g093"></a>WriteSet/CumWrites、readset、WR A/B、补集 | 单次/累计声明写范围、实际读范围；补集是该范围外。WR A/B分别检查自报范围稳定、原生变化被覆盖及CPU范围外不变，都是检查对象，不是网络层。 |
| <a id="g094"></a>所有权、唯一写回、exact-once、副作用、typed零写 | 谁能写某段内存、每个目的位置恰写一次等约束。副作用含完成槽等额外写；typed零写还规定宽度、值与时点。两个任务撞写一格会令“谁最后留下”不明确，不能只数输出长度。 |
| <a id="g095"></a>原子加、同址贡献、并行调度 | 多个任务向同一格累加；原子操作让一次读旧值/加/存不被其他任务拆开插入，但不自动确定谁先到。有限精度下到达次序仍可能改变结果。 |
| <a id="g096"></a>caller、宿主、API、句柄、surface、ABI | caller/宿主是外部提供输入控制的一方；API是调用接口，句柄标识资源，surface是可写图像资源接口；ABI约定参数字节布局等。知道这些含义不代表宿主生成分支已重建。 |
| <a id="g097"></a>小端/LE、NPZ/NPY、payload、codec、zigzag | 小端先放整数低字节；NPY存数组、NPZ封装多个数组；payload为实际载荷；codec是编码/解码方法；zigzag将有符号小整数映成便于保存的非负整数。这些属于存储表示。 |
| <a id="g098"></a>TwoSum、严格浮点编译、fast-math、隐式收缩、FE_TONEAREST | TwoSum用高低两部保存一次加法结果与误差信息；严格编译防止工具擅改求值。fast-math容许某些改写，隐式收缩可把乘加融合，FE_TONEAREST是最近舍入环境；各自不是网络层。 |
| <a id="g099"></a>runtime、checkout、镜像、资产加载 | runtime是运行接线代码，checkout是源码副本，镜像也可指内容副本；加载是把所需数据读入。与图像边界反射不同，副本路径也不等于内容身份。 |

<a id="address-status"></a>
### 地址公式与对照标签

先区分两件事：CLOSED/TABLE描述条目的规则或表依赖；EXACT、VACUOUS等描述一次对照或它的范围。它们不能互相替代。

| 标签 | 初读时怎样理解 |
|---|---|
| CLOSED / CLOSED_FORMULA | 对应审计条目已有显式规则，适用对象与范围按该条目声明；不表示公式已接入执行器，也不自动取得原生数值验收。 |
| TABLE | 该条目仍依赖给定表的数据；表可以在已测实例中正确工作，这个标签不是“运算失败”。 |
| EXACT / 0 | 此处地址表对照在声明的字段、几何和元素范围内完全相同，不一致项数为0；不是对所有输入或硬件内部结构的证明。 |
| VACUOUS | 比较对象为空数组，没有非空元素可检验；不能据此声称验证了非空地址规则。 |
| NOT_PRESENT | 指定来源里没有这个字段；不能按“字段内容全为零”理解。 |
| OUT_OF_SCOPE | 对象不属于这次比较声明的范围；不替它填写通过或失败。 |

“留出”指推导规则时未用于拟合、在公式冻结后才读取来对照的元素；不要求对应形状或元数据此前从未见过。地址表相等、实际执行器读取了哪张表、数值链验收和形式化证明仍是不同问题。
