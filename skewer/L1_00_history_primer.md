# 两帧、一次重置：旧颜色怎样成为新一帧的条件

上一站：[从零学一块](L1_00_one_block_primer.md) · 下一站：[有限数点与小篮](L1_00_numbers_primer.md) · [回索引](INDEX.md)

可选下钻：[B0精确取样](L3_b0_input.md#coordinates) · [B70独立取样](L3_b70_history_output.md#b70-temporal)

默认路线的id是存储位置的名字。id9是本帧刚算出的颜色[状态](APPENDIX_beginner_glossary.md#g002)；复制到id6后，成为下一帧可读取的旧状态。最终显示是id2，它来自另一条显示调整路径。[工作区](APPENDIX_beginner_glossary.md#g082)是计算的中间数和管理标记所在的存储，不等同于id6这张[历史](APPENDIX_beginner_glossary.md#g024)图。

<a id="timeline"></a>
## 两帧加一次重置，五条轨道分开看

| 轨道 | 帧t：正常使用历史 | 帧t+1：继续使用自己的结果 | 帧t+2：满足重置[合同](APPENDIX_beginner_glossary.md#g101) |
|---|---|---|---|
| 新输入 | 新当前图id1、新移动信息id3、控制参数 | 再刷新这些外部输入 | 仍需要本帧的新输入 |
| 颜色状态 | 读旧id6；算新id9→复制id6 | 读取t保存的id6；新id9再覆盖id6 | 不消费旧id6；本帧新id9在帧尾覆盖它 |
| 显示 | 新id9另经显示调整，与本帧原图备份混合→id2 | 同样另算id2；默认不拿id2回流 | 同样生成本帧显示；无需先把旧图抹零 |
| 工作存储 | CPU保留整片，自行逐[调用](APPENDIX_beginner_glossary.md#g080)覆写 | 接上t的自身工作区，不注入参考中间数 | 继续按真实写入合同覆写，不是全存储清零 |
| 扰动计数 | 从参数读计数，结合位置重新算三项扰动 | 读本帧参数指定的计数 | 可按[reset](APPENDIX_beginner_glossary.md#g032)记录回到0；只改计数不够 |

~~~mermaid
flowchart LR
    T["帧t：新输入 + 可用旧图"] --> N["新状态id9"] --> C["复制id9→id6"] --> T1["帧t+1：新输入 + t的id6"]
    N --> D["显示调整 + 本帧原图备份 → id2"]
    T1 --> C1["再次保存新id6"] --> R["帧t+2重置：跳过旧id6"] --> C2["帧尾新状态覆盖id6"]
~~~

reset表示**旧历史不被消费、帧尾被新状态替换**。模式、历史与移动资源标识等条件也要符合已记录的合同；计数=0不自动代表reset，任意控制变化也不自动代表reset。[精确守卫](L3_b0_input.md#guards)和[保存记录](L0_frame.md#两帧之间保留什么)保留适用范围。

## 两个历史取样路径，入口条件不同

~~~mermaid
flowchart TD
    H["旧图id6、移动信息id3、本帧控制"] --> B0G{"B0条件允许历史？"}
    B0G -->|"是"| S0["B0自己的坐标与五次过滤取样"] --> C0["旧RGB经输入变换 → 条件7至9"]
    B0G -->|"否"| NOW["条件7至9重复当前RGB"]
    H --> B70G{"B70历史路径有效？"}
    B70G -->|"是"| CONF{"资源置信尺度大于0？先检查"}
    CONF -->|"是，才取样"| S70["B70自己的移动取样、历史坐标与原始RGB取样"] --> MIX["第四预测量给混合份额，与当前颜色组合"]
    CONF -->|"否"| CUR["当前颜色路径继续；不取历史样本"]
    B70G -->|"否"| CUR
~~~

B0把旧颜色变成网络的输入条件；B70另取原始历史颜色作直接混合，两者不共用一次过滤结果。[置信尺度](APPENDIX_beginner_glossary.md#g052)关闭B70直接混合，不会自动关闭B0的历史条件。第四预测量参与混合[份额](APPENDIX_beginner_glossary.md#g048)，图像[第四通道](APPENDIX_beginner_glossary.md#g026)仍固定写1；显示强度[intensity](APPENDIX_beginner_glossary.md#g004)控制**最后显示与本帧备份的混合**，与历史份额是两个量。[置信检查与第四量](L3_b70_history_output.md#b70-mix)

## 一个明确参数的移动点

**人工B0坐标例，不是实测，也不规定所有[宿主](APPENDIX_beginner_glossary.md#g096)的方向或单位**：设宽高8×8，当前索引(2,3)，像素中心(2.5,3.5)；该处两个移动数=(0.5,−0.5)，两轴[尺度](APPENDIX_beginner_glossary.md#g031)都设1/8。按B0式，归一化历史中心=(0.375,0.375)，换回像素中心坐标=(3,3)，相当于连续像素索引(2.5,2.5)。x0=y0=2.5，两轴小数份额均0.5。方向来自**本例选定的正尺度**，不能据此给真实运动字段定通用语义。[原式与有限域](L3_b0_input.md#coordinates)

~~~text
                      · ● · ·                             · ○ · ·
                      · · · ·                             · · · ·
~~~

外层是左/上/中/下/右五个**[取样](APPENDIX_beginner_glossary.md#g027)点**，每点还要过滤四个邻居；不是总共只读五个像素。本例五点中心坐标为(1.5,3)、(3,1.5)、(3,3)、(3,4.5)、(4.5,3)。放大中间(3,3)：

~~~text

                             ○
         左(1.5,3) ○ ─── ○ ─── ○ 右(4.5,3)
                        中(3,3)
                             ○
                         下(3,4.5)
中点放大后的内层四角：
像素中心(2.5,2.5) ●──────● (3.5,2.5)
                  │  ○   │   ○ 是取样点(3,3)
~~~

内层四角按坐标过滤成一个值，外层五点再按另一套权重合并；外层[侧瓣](APPENDIX_beginner_glossary.md#g029)权重可为负，内层规则不能代替外层规则。精确取样还有限定坐标格与舍入，[五点](L3_b0_input.md#five-tap)和[四邻域](L4_tex_filter.md#tex-filter)分别给出。B70另有移动纹理和历史纹理变换，不套本例的B0直读位置。

<a id="workspace-memory"></a>
## 哪些旧工作区字节是真正必需的记忆？

**未定。** 已知有效历史路径消费id6，CPU自有链也实际保留整片工作区；但现有证据没有闭合“每个字节在本帧首次覆写前是否被数值读取”的最小跨帧集合。整片比较、声明写集以及前后同为零的快照，都不足以证明哪些旧字节能丢弃。可说明存储被复用，不能把全部旧中间数画成额外的学习记忆，也不能承诺随意清零不影响结果。[读写集的证据边界](APPENDIX_evidence_history.md#workspace-checker-sets)

工程上先按已验收的驱动保守保留：整片工作区，加上 158 路线的六张纹理对象（帧边界携带 id2、id6、id9、id10）。这是现有驱动的做法，不是最小必需记忆的证明；细节见 [两帧接续](REPRODUCE.md#two-frames)。

<a id="short-route"></a>
156路线的小分支是：末端直接写id2→复制id2到id6，省掉原图备份和独立显示调整，因此显示与历史共用结果。运行时消费已[冻结](APPENDIX_beginner_glossary.md#g103)的路线[描述符](APPENDIX_beginner_glossary.md#g088)；宿主怎样从控制生成该描述符仍未重建，不把具名分支条件推广成通用调度定律。[156合同](L3_b70_history_output.md#variants) · [宿主范围](L0a_object_method.md#route-scope-r04l)
