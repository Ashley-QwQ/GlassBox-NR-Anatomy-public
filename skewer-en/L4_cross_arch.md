## Shared Core, Platform Backends, and Actual Qualification

**[inferred / design, not yet a released artifact]** The scheme of "shared description/scheduling core + per-ISA scalar or accelerated backend + content-addressed assets" is explicitly marked in [BACKEND_RELEASE_ZH.md:1–25](../../../experiments/parity-cpp-opt-review-astra-r07-pi-20261012-codex/BACKEND_RELEASE_ZH.md#L1) as unimplemented/unreleased. The design requires each backend to bind content and execution seals, compiler, binary, assets, supported geometries/frames/modes, and byte-gate receipts, without inheriting another ISA's qualification merely because source code is shared, [same document:15](../../../experiments/parity-cpp-opt-review-astra-r07-pi-20261012-codex/BACKEND_RELEASE_ZH.md#L15). The current v2 repository lists 10 modules and Linux x86-64 precompiled payloads, [public README:18–24, 31](https://github.com/Ashley-QwQ/GlassBox-NR/blob/e4a9b4214c723015ff4a99d73f13aa9a4a8ed1ec/README.md#L18), so the split-package scheme above cannot be described as delivered.

**[measured, AVX2 isolated candidate]** In the R07 saved records, the AVX2 and combined candidates on i7-8700 passed the 1440 [reset](APPENDIX_beginner_glossary.md#g032) per-launch [FULL](APPENDIX_beginner_glossary.md#g105)/six-POST/FINAL and control gates; at the time, 1080 was still running / unrun and 4K was unrun. They are not full AVX2 receipts for public M2, [RESULT_ZH.md:53–58](../../../experiments/parity-cpp-opt-r07-exec-p0p2-r01-20261015-codex/RESULT_ZH.md#L53). The 100917516 zero-difference checks of the earlier AVX2 prototype belong to the prototype / teacher-forced scope of the legacy core and do not transfer as qualification for the sm_120 production core, [prototype RESULT:5–17](../../../experiments/parity-cpp-qmma-int-simd-proto-r01-20260928-codex/RESULT_ZH.md#L5).

**[measured, A53 scalar / M]** The M build on Pi 3B+ completed a 1080 f0 own-state chain FINAL match, with only the final-image gate; it is neither a per-launch gate nor a NEON backend acceptance. [ARCH:1246, 1552](../../../ARCHITECTURE_V3_ZH.md#L1246). Two-output integer parallelism on NEON is a design; the legacy A53 build explicitly disabled auto-vectorization, [Pi RESULT:123–129, 147](../../../experiments/parity-cpp-opt-review-astra-r07-pi-20261012-codex/RESULT_ZH.md#L123).

**[inferred / NOT_RUN, AVX-512]** The speed proposal reserves only the ABI and independent-output width, explicitly stating that there is no implementation, compilation, or on-device acceptance; a corresponding release backend and byte gate are not recorded, [speed RESULT:150–154](../../../experiments/parity-cpp-opt-review-astra-r07-speed-20261015-codex/RESULT_ZH.md#L150). None of the qualifications above provide a general compiler, scheduling, [aliasing](APPENDIX_beginner_glossary.md#g092), or full-domain hardware proof, [docs/arch-v2/08.03_portability.md:32](../../arch-v2/08.03_portability.md#L32).
