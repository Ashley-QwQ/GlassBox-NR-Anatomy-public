[CPU Reconstruction] Single [launch](APPENDIX_beginner_glossary.md#g080) of L2/B0: current color, valid [history](APPENDIX_beginner_glossary.md#g024)/[MV](APPENDIX_beginner_glossary.md#g023), and [params](APPENDIX_beginner_glossary.md#g083) → 16-[channel](APPENDIX_beginner_glossary.md#g007) [F16](APPENDIX_beginner_glossary.md#g054) conditioning → 32-channel [window](APPENDIX_beginner_glossary.md#g015) block → [full](APPENDIX_beginner_glossary.md#g018) X₀(32) and pool X₁(32) [E4](APPENDIX_beginner_glossary.md#g055). The five steps are intra-kernel steps and do not double-count launch coverage.
Shared contract: F16 adaptation uses [K16](APPENDIX_beginner_glossary.md#g065); trunk E4 [matrices](APPENDIX_beginner_glossary.md#g051) [publish](APPENDIX_beginner_glossary.md#g091) half at each K32; conversions, [residuals](APPENDIX_beginner_glossary.md#g017), and half pooling each preserve their own rounding points. Missing [resources](APPENDIX_beginner_glossary.md#g079) and out-of-domain primitives are still rejected; [p5](APPENDIX_beginner_glossary.md#g032) selection executes according to the conditioning-channel contract drilled into below.

| Intra-kernel step | Specific role and handoff of this step | Drill-down |
|---|---|---|
| <a id="noise"></a>Noise | Un-[mirrored](APPENDIX_beginner_glossary.md#g030) (x,y,f) hash → three-channel half noise, with no recurrent [RNG](APPENDIX_beginner_glossary.md#g075) [state](APPENDIX_beginner_glossary.md#g002) | [Noise](L3_b0_input.md#noise) |
| <a id="temporal"></a>History [reprojection](APPENDIX_beginner_glossary.md#g025) | [5-tap](APPENDIX_beginner_glossary.md#g029) with MV when valid; otherwise repeats current RGB | [Coordinates / 5-tap](L3_b0_input.md#coordinates) |
| <a id="channels"></a>16 channels | Keeps original controls when p5=false; when p5 is true, the reset / temporal branch sets [structure](APPENDIX_beginner_glossary.md#g005)=1 and takes [masks](APPENDIX_beginner_glossary.md#g006) from CB+0xb8 ([f32](APPENDIX_beginner_glossary.md#g057))/CB+0xbc (f32), with 15 as [+0](APPENDIX_beginner_glossary.md#g070) | [Channels and child candidates](L3_b0_input.md#p5-candidates) |
| <a id="adapter"></a>Adapter and window block | 16→32 F16 adaptation → [FFN](APPENDIX_beginner_glossary.md#g037) → Q/K [normalization](APPENDIX_beginner_glossary.md#g043) → [attention](APPENDIX_beginner_glossary.md#g039) → [projection](APPENDIX_beginner_glossary.md#g038) | [Full block](L3_b0_input.md#adapter) |
| <a id="publish"></a>full/pool | Un-[quantized](APPENDIX_beginner_glossary.md#g061) result splits into two paths; full quantizes directly, while pool averages 2×2 in fixed half order first and then quantizes | [Layout and arithmetic](L3_b0_input.md#publish) |

When p5 is true, structure is fixed and the two masks are taken from the control buffer, using own-history reprojection when history is available; [parameter branch evidence](APPENDIX_evidence_history.md#param-change) (measured on child candidate).

~~~mermaid
flowchart LR
    N["Coordinates / frame word → noise"] --> C["16-channel F16"]
    T["Current color / valid MV history → reprojection"] --> C
    C --> A["F16 adaptation 16→32"]
    A --> W["FFN → Q/K normalization → attention → projection"]
    W --> F["Q8 → full"]
    W --> P["half 2×2 average → Q8 → pool"]
~~~
