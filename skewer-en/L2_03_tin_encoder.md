[TIN](APPENDIX_beginner_glossary.md#g011) is the [window](APPENDIX_beginner_glossary.md#g015)-block [family](APPENDIX_beginner_glossary.md#g080) in this skewer; [inpview](APPENDIX_beginner_glossary.md#g022), chained, and ds_wait are the input-view block, same-tier consecutive block, and [downsampling](APPENDIX_beginner_glossary.md#g021) terminal block respectively. For [E4](APPENDIX_beginner_glossary.md#g055)/[F16](APPENDIX_beginner_glossary.md#g054), [K32](APPENDIX_beginner_glossary.md#g065), [RN-even](APPENDIX_beginner_glossary.md#g059), [full](APPENDIX_beginner_glossary.md#g018)/pool, [seed](APPENDIX_beginner_glossary.md#g042), and X_r(C), see the [notation table](INDEX.md#shape-and-workspace-notation); spatial shapes on this page follow that table, and the [M×K×N](APPENDIX_beginner_glossary.md#g051) and single-head / multi-head decomposition of [FFN](APPENDIX_beginner_glossary.md#g037) are in [L3.ffn](L3_ffn.md#channels), without inferring other window sub-layers backward from execution-indexing axes.

## Shared Computation of the Three Families

- **What inpview is / input → output / how it is computed:** Unpacks the previous tier's [planar-split](APPENDIX_beginner_glossary.md#g088) pool into this tier's [logical](APPENDIX_beginner_glossary.md#g085) positions; extracts 8×8 windows according to the actual window shift and zero-pads out-of-bounds [tokens](APPENDIX_beginner_glossary.md#g041); executes feed-forward, Q/K [normalization](APPENDIX_beginner_glossary.md#g043), window [attention](APPENDIX_beginner_glossary.md#g039), and [residual](APPENDIX_beginner_glossary.md#g017) [projection](APPENDIX_beginner_glossary.md#g038); after [quantization](APPENDIX_beginner_glossary.md#g061), writes out in the internal layout and [publishes](APPENDIX_beginner_glossary.md#g091) completion flags. Input and output have the same tier and [channel](APPENDIX_beginner_glossary.md#g007) count.
- **What chained is / input → output / how it is computed:** Fetches the current block input from this tier's internal layout; partitions into windows at the current origin and zero-pads; executes same-tier feed-forward and window attention, retaining the current-window input and feed-forward residuals respectively; writes back and publishes at the original quantization points. The [encoder](APPENDIX_beginner_glossary.md#g009) and decoder share the family, without sharing numeric values, [weights](APPENDIX_beginner_glossary.md#g079), or residuals.
- **What ds_wait is / input → output / how it is computed:** First executes this tier's final window block; sends the unquantized result along two paths: one is quantized directly into full and saved as the decoder [skip](APPENDIX_beginner_glossary.md#g016); the other averages 2×2 half values in a fixed two-row order, quantizes the [mean](APPENDIX_beginner_glossary.md#g044) first, and then projects to twice the channels and writes the next tier's pool. Completes padding writes and control handoff per instance; pooling cannot be recomputed by decoding from the already-quantized full.
- **Numeric rules:** Input and matrix weights are E4, publishing F16 at each K32; half RN-even, E4 saturating quantization, fusion, and residual publication order remain unchanged, and zero-padded positions still participate in attention. Residual sources and quantization differences are specified by the shared core and the table below; for half [scale](APPENDIX_beginner_glossary.md#g031) multiplication, see [Complete TIN Block](L3_tin_window.md#tin-window). In L6 CPU norm, summing positive numbers can reach [Inf](APPENDIX_beginner_glossary.md#g069), so finite inputs do not guarantee finite intermediates; function-domain and QMMA [overflow](APPENDIX_beginner_glossary.md#g071) rejections are retained according to the [nonfinite contract](L3_norm_nonfinite.md#nf-path).
- **Why:** inpview connects the previous tier's physical view; chained processes positional relationships within the same scale; ds_wait simultaneously hands off a fine-scale bypass and a smaller main path. Training motivations, window-schedule choices, and hardware causes of fusion boundaries are not established; causality is not supplied from kernel names.
