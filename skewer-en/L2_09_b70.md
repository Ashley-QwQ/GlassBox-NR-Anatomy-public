### L2.09.b70 post_block and Temporal State (1 Launch)

- Coverage: L155 / B70.
- What it is: Generates the id9 [state](APPENDIX_beginner_glossary.md#g002) [texture](APPENDIX_beginner_glossary.md#g027) from the [decoder](APPENDIX_beginner_glossary.md#g009) main path, the entry [bypass](APPENDIX_beginner_glossary.md#g016), and image/[temporal](APPENDIX_beginner_glossary.md#g024) conditions.
- Input → output: B69 [outview](APPENDIX_beginner_glossary.md#g022), B0 [full](APPENDIX_beginner_glossary.md#g018) (full-internal-canvas 32-[channel](APPENDIX_beginner_glossary.md#g007) bypass) [E4](APPENDIX_beginner_glossary.md#g055), and id1; reads id3 and id6 when history is valid → height H × width W × 4 [F16](APPENDIX_beginner_glossary.md#g054) values in id9.
- How it is computed:
  ~~~text
  1. Read the B69 main path and B0 bypass according to their respective layouts, scale them separately, and merge
  2. Execute feed-forward, query/key normalization, attention, and projection of the 1-head window block
  3. Use the terminal half matrix to generate RGB and, when not reset, the fourth predicted value
  4. Combine with current color; when history is valid and the confidence value permits, separately perform 5-tap reprojection and blending
  5. Crop back to valid image dimensions, convert RGB to half toward zero, and write alpha as 1
  ~~~
- Numeric rules: Internal E4/half [matrices](APPENDIX_beginner_glossary.md#g051), [quantization](APPENDIX_beginner_glossary.md#g061), and original [residual](APPENDIX_beginner_glossary.md#g017) order are preserved; temporal coordinates and blending use [F32](APPENDIX_beginner_glossary.md#g056) and captured [function tables](APPENDIX_beginner_glossary.md#g074); the tail end uses [RZ](APPENDIX_beginner_glossary.md#g060), not half [RN-even](APPENDIX_beginner_glossary.md#g059); out-of-domain guards are retained.
- Per-instance variation: Entry/decoded [features](APPENDIX_beginner_glossary.md#g008), color, history, motion, parameters, and geometry are [bound](APPENDIX_beginner_glossary.md#g103) per frame; non-[reset](APPENDIX_beginner_glossary.md#g032) frames additionally compute the fourth predicted value and consume history, whereas reset cannot pretend to have the same history; [weights](APPENDIX_beginner_glossary.md#g079) are taken from the current instance.
- Why it is computed this way: Forms the temporal state to be used by the next frame while retaining the result prior to display postprocessing.
- How we know: [CENSUS](APPENDIX_beginner_glossary.md#g100) (current [M2](APPENDIX_beginner_glossary.md#g107) behavior), MEASURED (named multiframe runs in ARCH); [ARCH 0.7 §6.3, §6.8](../../../ARCHITECTURE_V3_ZH.md#68-07-尾段及跨帧状态).
