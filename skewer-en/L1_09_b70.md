[CPU Reconstruction] Stage wiring is given below; [unified notation](INDEX.md#shape-and-workspace-notation) and [computation conventions](INDEX.md#computation-conventions) are collected in the index.

- Function: B70 combines [decoded](APPENDIX_beginner_glossary.md#g009) [features](APPENDIX_beginner_glossary.md#g008), the B0 [bypass](APPENDIX_beginner_glossary.md#g016), and color/history conditions into the current temporal state id9.
- Input → output: B69.[outview](APPENDIX_beginner_glossary.md#g022) X₁(32) [E4](APPENDIX_beginner_glossary.md#g055), B0.[full](APPENDIX_beginner_glossary.md#g018) X₀(32) E4, id1, and valid id3/id6 → W×H×4 [F16](APPENDIX_beginner_glossary.md#g054) id9.
- Computation order: Reuse the main path by floor(x/2),floor(y/2) and merge with the B0 bypass → [window](APPENDIX_beginner_glossary.md#g015) block → F16 terminal head → current-color combination and valid-history blending.
- Key exceptions: Having the same byte length as X₀(8) does not mean the main path can be reshaped into full-resolution 8 [channels](APPENDIX_beginner_glossary.md#g007). The terminal head uses two-step [K16](APPENDIX_beginner_glossary.md#g065); the color exit converts to F16 via [RZ](APPENDIX_beginner_glossary.md#g060) with [alpha](APPENDIX_beginner_glossary.md#g026)=1, and guards follow the specific path.
- How we know: [CENSUS](APPENDIX_beginner_glossary.md#g100) / INFERRED ([M2](APPENDIX_beginner_glossary.md#g107) source behavior; legacy history-sampling blocker records do not represent the current entry); [b70 and run in chain_outtail_optm/outtail.cpp](https://github.com/Ashley-QwQ/GlassBox-NR/blob/e4a9b4214c723015ff4a99d73f13aa9a4a8ed1ec/cpp/chain_outtail_optm/outtail.cpp); multiframe numeric coverage is distinguished by [build](APPENDIX_beginner_glossary.md#g103) and reference in INDEX.
